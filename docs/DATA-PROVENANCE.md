# Data provenance

This public candidate contains no retained research database, downloaded website body, source-cache document, real-person biography, email list, contact export, source snapshot or customer record.

The fixture generator authors three new sponsors (Demo Sponsor Alder, Birch and Cedar), three corresponding Demo Hospitals and explicit DEMO trial identifiers. They are invented examples, not aliases for the private retained records. Empty role lists and missing source evidence are intentional. The separate CRM/reply practice scenarios were already fictional and remain labeled as such.

`demo-schema.json` contains software table/index definitions only. It has no row values or original source excerpts. `cell.json`, `gene.json` and `fit-reviewed-events.json` are empty compatibility fixtures, not a hidden copy of the registry corpus.

The original working project and its retained data remain private and unchanged. No third-party dataset license is inferred from the fact that its website was readable. No source cache is relicensed under the code license.

Screenshots in this candidate were captured from the newly generated fictional dataset. The older local portfolio video uses a different, larger retained-public-research demo. Its publication was separately approved after a media privacy review. The video is available from the repository's Releases page and is not the dataset shipped in this source.
